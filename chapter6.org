* Viewing Network Connections

- *netstat* program offers network statistics on both Windows and Unix
  systems. It lets you see which ports a server has open, current
  connection to other machines and sometimes what's listening on a
  port.

* Hostnames and Netstat

- By default, netsat attempts to use hostnames instead of IP
  addresses. This means your server perfroms a rever DNS lookup on
  every IP address it exchanges traffic with.
- It also uses service (/etc/services) file to give named port in it's
  output.
- Netstat allows you to disable DNS lookups and port name lookups with
  the /-n/ flag which is recommended.

* Netstat Display

** Display headers

#+begin_src sh :exports both :eval never-export :results verbatim
netstat | head -n 3
#+end_src

#+RESULTS:
: Active Internet connections (w/o servers)
: Proto Recv-Q Send-Q Local Address           Foreign Address         State
: tcp        0      0 arya:55348              172.65.251.78:https     ESTABLISHED

- Proto: Shows if it involves TCP, UDP or some other protocol.
- Recv-Q: The count of bytes not copied by the user program connected to this socket.
- Send-Q: The count of bytes not acknowledged by the remote host.
- Local Address: IP address on the local systems that this connection
  or socket uses.
- Foreign Address: Shows the IP address and port at the remote end of
  the connection.
- State: shows the condation of the TCP connection.

The above command with /-n/ flag:

#+begin_src sh :exports both :eval never-export :results verbatim
netstat -n | head -n 3
#+end_src

#+RESULTS:
: Active Internet connections (w/o servers)
: Proto Recv-Q Send-Q Local Address           Foreign Address         State
: tcp        0      0 192.168.0.181:55348     172.65.251.78:443       ESTABLISHED

** Reading Netstat Entries

Sample entry:

#+begin_example
TCP 0.0.0.0:135 0.0.0.0:0 LISTENING
#+end_example

- The local address 0.0.0.0 means "all IP addresses on this
  machine". If you add new IP addresses to this hist, even without
  rebooting this socket will be available to them.
- The foreign address is 0.0.0.0 which means "any address". Similary
  port 0 means "any port". The LISTENING state means that the software
  is waiting for an incoming connection. This is an open, idle socket.
- TIME_WAIT state indicats the connection is finished and being torn
  down.

Let's see another sample entry:

#+begin_example
UDP 0.0.0.0:100001 *:*
#+end_example

- *:* is UDP's way of saying "any IP, any port". Note that there is no
  state for UDP, since UDP is connectionless.

* Unix Netstat

** Live ports

Options:

- *-a*: Show live connections
- *-n*: Disable DNS lookup and port to name conversion
- *-4*: Show IPv4 ports

  to that port.
